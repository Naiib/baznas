NEXT.JS FRONTEND MIGRATION IMPLEMENTATION PLAN

GOAL
Memigrasikan frontend BAZNAS Data Center dari React + Vite + JavaScript ke Next.js 16 App Router + React 19 + TypeScript strict + Tailwind CSS v4, tanpa menghentikan backend Express/PostgreSQL atau mengubah perilaku produk yang sudah live.

ARCHITECTURE
Gunakan migrasi paralel (blue/green): buat aplikasi Next baru pada frontend-next/, sementara Vite lama dan Express API tetap berjalan sampai seluruh rute penting lolos parity check. Next menangani rendering, routing, metadata, dan static assets; Express di port 3001 tetap menjadi satu-satunya sumber API dan autentikasi selama fase ini. Halaman terautentikasi tetap memakai Client Components pada batas interaktif; gunakan Server Components hanya untuk layout, metadata, dan elemen yang tidak membutuhkan token browser.

TECH STACK
Next.js 16 App Router, React 19, TypeScript 5.8 strict, Tailwind CSS v4 dengan @tailwindcss/postcss, Vitest + Testing Library, Express 5 API existing, React Leaflet 5.

GLOBAL CONSTRAINTS
- Jangan menghapus atau menulis ulang src/, server/, atau deployment Vite lama sebelum versi Next melewati UAT.
- Jangan mengklaim ada 34 rute/artikel atau menggunakan generateStaticParams; proyek saat ini tidak memilikinya. Terapkan SSG hanya pada rute publik yang benar-benar statis setelah rute tersebut ada.
- Pertahankan API Express: /api/auth/*, /api/mustahik/*, /api/penyaluran/by-kecamatan, dan /api/data/overview.
- Konsep 3 adalah beranda Penyaluran tunggal pada /penyaluran; jangan membuat mode preview atau query concept baru.
- Poin dashboard periode/asnaf/program belum termasuk migrasi ini. Hanya siapkan fondasi typed API agar fitur itu dapat ditambahkan setelah cutover.
- Semua akses token browser harus berada dalam Client Components. Jangan membaca localStorage dalam Server Component.
- Peta React Leaflet harus dimuat dengan dynamic(..., { ssr: false }).
- Gunakan NEXT_PUBLIC_API_BASE_URL untuk URL backend, tanpa hard-code IP/domain.

TARGET ROUTE MAP
- penyaluran -> /penyaluran -> authenticated Client dashboard di shared App Router layout
- mustahik -> /penyaluran/mustahik -> authenticated interactive
- program_bantuan -> /penyaluran/program -> authenticated interactive
- peta_sebaran -> /penyaluran/peta -> authenticated, map client-only
- laporan_penyaluran -> /penyaluran/laporan -> authenticated interactive
- login -> /login -> client form
- portal public -> / -> server-rendered public entry

6. Add scripts: dev, build, start, lint, test, typecheck.
